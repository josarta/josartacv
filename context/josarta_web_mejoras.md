# Plan de Mejora — Portafolio Personal de José Luis Sarta

## Objetivo

Transformar la web personal de un portfolio técnico atractivo en una **marca profesional orientada a contratación**, posicionada alrededor de:

> **AI Systems Engineer · SRE · Intelligent Automation**

# 7. Revisar las métricas técnicas

La web utiliza métricas como:

- 99.99% SLA
- <12ms latency
- 0 ms Deterministic Stability Margin

Estas métricas deben mantenerse únicamente si pueden defenderse técnicamente.

## Para cada métrica especificar

- ¿Qué se mide?
- ¿Durante qué periodo?
- ¿Cuál es la unidad?
- ¿Qué percentil corresponde?
- ¿Es SLA, SLO o una medición interna?
- ¿Cuál fue la responsabilidad directa?
- ¿Es información públicamente compartible?

### Ejemplo

En lugar de:

> <12ms Latency

usar, si es verdadero:

> P99 latency <12 ms

o, si no se puede publicar:

> Low-latency distributed systems

## Evitar

> 0 ms Deterministic Stability Margin

si no tiene una explicación clara y comprensible.

# 18. Crear Engineering Principles

Una sección con principios personales de ingeniería.

## 01 — Reliability before complexity

> A sophisticated AI system that cannot be observed or recovered is not production-ready.

## 02 — Measure before optimizing

> Latency, cost and quality need instrumentation before optimization.

## 03 — Probabilistic AI, deterministic boundaries

> Models can be probabilistic. Critical system boundaries should not be.

## 04 — Every failure becomes an evaluation

> Production incidents should improve the next version of the system.

Esta sección ayuda a diferenciar la marca personal del simple listado de tecnologías.
